# Project Documentation

- `discovery/` contains call notes, screenshots, engagement summaries, the hackathon log, and data-room analysis.
- `engagement/` contains the official scenario guide and the working engagement pack.
- `governance/` contains prototype evaluation and repository/process decisions.

Client-facing outputs belong in `../deliverables/`, canonical mock documents in `../assets/source/`, and immutable skill versions in `../releases/`.
