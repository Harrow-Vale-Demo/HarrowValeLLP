# Archived job logs (.ai/jobs/done)

This folder holds completed job logs moved from `.ai/jobs/active/`.

Also see:
- `.ai/jobs/done/INDEX.md` (append-only index of all completed jobs)

Recommended filename:
- `YYYY-MM-DD_HHMMUTC_Jx - <title>.md`

What to include in a completed job log:
- `Initiated by (human)` preserved unchanged from the active job
- a timestamped three-checkpoint attribution-attempt log whenever the initiator is unresolved; do not archive at attempt 1/3 or 2/3
- tasks finalized (all ✅ or ⛔)
- final activity line (timestamped)
- validation (ran/not run)
- optional: link to related PR/commit, and any follow-up jobs created

BLACKBOARD `Recent History` should stay short; use this folder for full history.
