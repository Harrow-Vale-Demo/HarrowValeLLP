# Checklist Applicability by Instrument Type

The DD checklist (`dd-checklist.md`) applies to the whole matter, not to any single document. A term sheet is one input among many. Use this table to decide whether a checklist item's absence *from the term sheet* is:
- **Expected** (this item never lives in a term sheet — it's a separate data-room document; only flag if it's also missing from the wider document set you were given),
- **Relevant** (this instrument type would normally address this in the term sheet, so absence is worth a checklist "omitted" flag), or
- **N/A** (this checklist item doesn't apply to this instrument type at all).

| Checklist item | SAFE | Priced equity round | Convertible loan note |
|---|---|---|---|
| Certificate of incorporation | Expected (data room) | Expected (data room) | Expected (data room) |
| Articles of Association | Expected (data room) | Relevant — priced rounds usually amend Articles at close | Expected (data room) |
| Cap table / register of members | Expected (data room) | Relevant — should reconcile with round math | Expected (data room) |
| All outstanding SAFEs/convertibles/options | Relevant — MFN clauses depend on knowing what else exists | Relevant — informs fully diluted calc | Relevant — MFN/most-favoured comparisons |
| Side letters affecting share rights | Relevant if referenced | Relevant if referenced | Relevant if referenced |
| Material contracts (customer/supplier/lease/loan) | Expected (data room) | Expected (data room) | Expected (data room) |
| IP assignment / trademarks / OSS summary | Expected (data room) | Expected (data room) | Expected (data room) |
| Employment/contractor agreements | Expected (data room) | Expected (data room) | Expected (data room) |
| Litigation & compliance | Expected (data room) | Expected (data room) | Expected (data room) |
| Financials & tax | Expected (data room) | Expected (data room) | Expected (data room) |
| Insurance | Expected (data room) | Expected (data room) | Expected (data room) |
| Related-party transactions | Expected (data room) | Expected (data room) | Expected (data room) |
| Founder vesting schedule | Expected (data room) — typically in Founders' Agreement or employment contracts | Relevant — investors usually require vesting at priced rounds; flag if absent | Expected (data room) — notes rarely address founder vesting |
| Legal fees & expenses | Relevant — SAFEs sometimes state fee arrangements | Relevant — priced rounds should specify who pays and any cap | Relevant — notes sometimes state fee arrangements |

**Reading this table:** for "Expected (data room)" items, the skill should not treat their absence from the term sheet as an omission — it should only flag them as missing if a data-room folder was supplied alongside the term sheet and the document genuinely isn't there. For "Relevant" items, absence from the term sheet itself is worth surfacing as a checklist gap the reviewing lawyer should chase.
