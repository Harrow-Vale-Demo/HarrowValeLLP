# Proposal source

- `Harrow-Vale-Proposal.pdf` is the presentation-ready proposal.
- `Harrow-Vale-Proposal.docx` is the editable Word version.
- `build_proposal.js` regenerates the Word document.

To rebuild from this directory:

```powershell
npm ci
node build_proposal.js
```

The PDF is a checked-in presentation artifact and is not regenerated by the JavaScript command.
